DSH Desktop 安装说明
====================

【安装步骤】（只需一步）

双击「DSH Desktop」即可完成安装，无需运行其他文件：
- 首次打开会自动安装运行环境（node + dsh，约 300MB，视网络需要几分钟），
  界面会显示安装进度，完成后自动进入 DSH。
- App 会自动复制到「应用程序」文件夹（从磁盘镜像、下载、桌面双击都行），
  以后从启动台打开即可。
- 升级也一样：双击新版本即自动替换旧版（若已存在会弹窗询问：
  替换 / 保留两者 / 取消）。
- 如果提示"无法打开 / 来自身份不明的开发者"：
  右键点击「DSH Desktop」→ 打开 → 再点「打开」，之后正常进行。
- 提示：若之前已安装过 DSH Desktop，安装时请先退出正在运行的版本。

【配置 API Key】

装好后打开 DSH，在「设置 → 模型」里填写自己的 DeepSeek API Key
（sk- 开头，在 platform.deepseek.com 获取），即可开始使用。

【视觉识别（可选）】

App 已内置视觉识别插件。在「设置 → 插件 → 插件配置 → 视觉识别」中：
1. 选择「自定义」
2. 填写你的多模态模型（任意 OpenAI 兼容接口）：
   - API 地址：如 https://token-plan-cn.xiaomimimo.com/v1（小米 MiMo）、
     https://open.bigmodel.cn/api/paas/v4（智谱）等
   - 模型 ID：如 mimo-v2.5 / glm-4v-flash / qwen-vl-plus
   - API Key
3. 保存后，对话中粘贴/上传图片即可自动识别。

不配置也能正常使用（纯文字对话不受影响）。

【更新】

已安装的版本会自动检查更新（App 本身 + DeepSeek Harness 运行时）：
发现新版本时会弹提示，点击下载/升级即可；也可随时在菜单栏
「DSH → 检查更新…」「DSH → 检查 DeepSeek Harness 更新…」手动查看。

【常见问题】

- 双击被拦？ → 右键 → 打开（一次性），之后正常。
- 首次安装很慢？ → 下载运行环境约 300MB，请耐心等待；失败会自动重试。
- 想卸载？ → 删除 ~/Applications/DSH Desktop.app；
  如需彻底清除 dsh：终端执行 npm uninstall -g @deepseek-ai/dsh。
- Intel 和 Apple Silicon 的 Mac 均支持，需要 macOS 13 及以上。
