DSH Desktop 安装说明
====================

【安装步骤】

1. 双击「DSH Desktop」即可，无需运行其他文件。
   - 首次打开会自动安装运行环境（node + dsh，约 300MB，视网络需要几分钟），
     界面会显示安装进度，完成后自动进入 DSH。
   - 从磁盘镜像双击时，App 会自动复制到「应用程序」文件夹，以后从启动台打开。
   - 升级也一样：双击新版本里的「DSH Desktop」即自动替换旧版。
   - 若「应用程序」里已有 DSH Desktop，会弹窗询问：替换 / 保留两者（另存为
     "DSH Desktop 2.app"）/ 取消——与 macOS 标准安装行为一致。
   - 如果提示"无法打开 / 来自身份不明的开发者"：
     右键点击「DSH Desktop」→ 打开 → 再点「打开」，之后正常进行。

2. 装好后打开 DSH，在「设置 → 模型」里填写自己的 DeepSeek API Key
   （sk- 开头，在 platform.deepseek.com 获取），即可开始使用。

3. 已安装的版本会自动检查更新：发现新版本时会弹提示，点击下载即可；
   也可随时在菜单栏「DSH → 检查更新…」手动查看。

【备选：手动安装（一般不需要）】

自动安装失败时（如网络问题），可双击「安装.command」在终端里手动安装，
它会显示每一步的进度，并支持直接输入 API Key。

【常见问题】

- 双击被拦？ → 见第 1 步：右键 → 打开（一次性）。
- 自动安装很慢？ → 首次下载约 300MB，请耐心等待；失败可重试或走「安装.command」。
- 想卸载？ → 删除 ~/Applications/DSH Desktop.app；
  如需彻底清除 dsh：终端执行 npm uninstall -g @deepseek-ai/dsh。
- Intel 和 Apple Silicon 的 Mac 均支持，需要 macOS 13 及以上。
